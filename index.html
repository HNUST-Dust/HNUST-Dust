01 ABOUT DUST

不只是造一台机器人

在真实问题里，
成为真正的工程师。

DUST 是一支由学生驱动的机器人战队。我们围绕机器人控制、嵌入式系统、计算机视觉、导航算法与机械设计展开研发，让跨学科想法在赛场与真实系统中接受检验。

这里没有旁观者。每一行代码、每一块电路板、每一个结构件，都来自成员的持续迭代与协作。

03 GROWTH PATH

DUST 培养计划

从零到独当一面，
每一步都有回声。

进入 DUST 课程中心24 节课程 · 4 条路线 →
STAGE01
0—1 个月

基础筑基

完成方向入门任务，掌握工具链与工程规范；在导师和学长的反馈中，建立可靠的技术习惯。

  • 工具链与 Git 协作
  • 安全规范与基础训练
  • 第一次代码 / 设计评审
STAGE02
1—3 个月

项目实战

进入真实项目小组，在明确的模块目标中完成开发、测试与文档，把知识变成可运行的成果。

  • 结对开发与周复盘
  • 模块级任务交付
  • 真实机器人联调
STAGE03
3 个月以后

独立担当

负责关键模块或带领小组，参与技术决策、竞赛备战与开源建设，并把经验传递给下一届。

  • 系统级方案设计
  • 技术分享与新人指导
  • 开源贡献与赛事验证
